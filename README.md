# room-items-psd

`v0.1.0-beta` 内部试用版。仓库：`ziyuechen0-art/room-items-psd`，Private。Photoshop 功能及跨电脑测试尚未验收。

按空间位置、物体功能和遮挡关系整理房间场景 PSD，合并为可独立编辑的对象。完整规则集中在 [SKILL.md](skills/room-items-psd/SKILL.md)，无外部案例文档依赖。

## 默认交付规范

以下为默认强制要求，仅使用者明确提出不同交付要求时允许调整：

- 3413×1920 横版画布（约 16:9，以像素尺寸为准）；中央 1080×1920 的 9:16 安全区，两侧黑色遮挡参考，默认 45%。
- 恰好 25 个独立物体，人物计入、底座不计入；全部为可编辑智能对象。
- 命名 items1 至 items25，可带必要说明后缀；面板从上到下 items25 至 items1，编号服从正确遮挡。
- 固定顶层从上到下：`9:16`、`items`、`di`、`bj`；di 内完整底座智能对象名为 dizuo。
- 保留完整源像素、隐藏部件、必要层序和视觉关系；人物独立，按功能合理合并家具与物品。甜品专项及其他独立编辑要求遵循 Skill。
- 独立输出 `fjzl-psd-YYMMDD_3413x1920.psd`，不覆盖源 PSD；执行源完整性、结构及视觉验收。

## Photoshop 依赖与首次使用

1. 安装并启动合法可用的 Photoshop。由团队维护者提供和配置已验证的 Photoshop MCP 或等价执行通道；仓库不附插件、服务器、配置文件或自动安装器。
2. 在 Codex 只读验证连接、活动文档身份、层树与预览；在授权测试副本确认智能对象转换、另存和重新打开能力。发现工具名称不等于已连接成功。
3. 提供自己的 PSD 和独立输出目录，先获取对象映射及遮挡冲突，再执行。原素材必须有使用权限，禁止为了凑数删除隐藏对象或破坏像素。
4. 按 SKILL.md 逐项检查并记录。不能满足 25 个对象、完整像素和层序时说明冲突，等待明确选择，不静默放宽规范。

```text
$room-items-psd 整理 ./input/room.psd，独立输出到 ./output/。
按 Skill 全部默认规范交付，人物独立，保留源像素和隐藏状态。
先给出 25 个对象的合并映射与遮挡检查，再处理并报告结构、完整性及视觉验收结果。
```

文件路径相对当前任务目录；仓库不含示例 PSD。没有可用 Photoshop 执行通道时，只能提供规则分析、合并规划和操作指导，不能自动编辑或保证交付。Python／psd-tools 可选用于只读分析，不是运行 Skill 的必装依赖；PhotoCraft 未验证为等价替代工具。没有不可缺少的随包执行脚本。
